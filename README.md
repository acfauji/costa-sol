# COSTA SOL: Heatwave

An original open-world crime game — built as a make.fun gta6-01 entry.

[![make.fun](https://make.fun/images/badge.svg)](https://make.fun/c/gta6-01)

- **City:** COSTA SOL — a sun-soaked grid of streets, blocks, and varied buildings
- **Play:** on foot or steal any car; traffic, pedestrians, police chases
- **Systems:** wanted level, five story missions, combat, HUD + minimap, save/load
- **Audio:** synthesized engine/ambient/effects, no external assets

Play it by opening `game/index.html` in a desktop browser.
