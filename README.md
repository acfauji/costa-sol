# COSTA SOL: Heatwave

An original open-world crime game built for the make.fun "Make GTA 6" bounty (gta6-01): your own sun-soaked city, characters, vehicles, story, art and sound — nothing from any commercial game.

## Run

Open `game/index.html` in a desktop browser (Chrome recommended). No build step, no network requests — everything loads from `game/`.

## The game

Steal any car, drive the sun-soaked streets, fight and evade police, complete story missions. Includes a minimap, HUD, wanted level, missions, combat, and save/load.
